Voice Triage Agent

A voice interface for triaging support tickets that can be interrupted mid-response, not just talked over.

Demo mode connects without asking for microphone access -- type what the caller says below instead of speaking. Useful for a quick demo, or if a mic isn't available; the real pipeline (VAD, transcription, the LLM response, TTS playback, and barge-in) runs exactly the same either way.

Status: not started

Tip: submit a second line while the agent is still replying to trigger a real barge-in.
